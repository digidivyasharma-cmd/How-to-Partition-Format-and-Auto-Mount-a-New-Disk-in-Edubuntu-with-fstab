# How-to-Partition-Format-and-Auto-Mount-a-New-Disk-in-Edubuntu-with-fstab
Every system runs low on storage sooner or later. You install new software, save project files, or download large datasets, and the main disk fills up. Adding a second disk is the easiest fix. But a brand-new disk is empty, so you must first partition it, format it, and mount it before Edubuntu can store any files on it.
